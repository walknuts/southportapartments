# Southport Apartments

Static site for the Southport Apartments residential community on Lake Tuggeranong, Canberra. Built with Astro 6.

## Develop

```sh
pnpm install
pnpm dev
```

## Build

```sh
pnpm build
```

Output is in `dist/`.

## Content

- `src/content/pages/` — main site pages
- `src/content/posts/` — news/blog posts
- `src/assets/images/` — content imagery (processed by Astro `<Image>`)
- `public/downloads/` — PDFs
